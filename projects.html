  1. Professional case study · Firmware

    Embedded Measurement and Calibration Platform

    A generalized view of firmware developed for measurement and test systems. The work brings together ADC-based acquisition, signal processing and filtering, calibration algorithms, EEPROM-backed parameter storage, and device communication.

    Engineering scope

    • Embedded firmware in modern C
    • Acquisition, filtering, and calibration pipelines
    • Persistent parameter management
    • Device communication and validation tooling

  2. Professional case study · Integration

    Embedded Linux HMI Integration

    An integrated path from embedded device to operator interface: a Buildroot-based Linux target, cross-compiled software, a Qt/QML interface, and structured UART communication with embedded hardware.

    Engineering scope

    • Buildroot-based embedded Linux
    • Qt/QML interface development
    • Cross-compilation and target deployment
    • UART command-response communication
    • Debugging and system integration

  3. Professional case study · Verification

    Communication Protocol Test Tools

    PC-side tools for exercising embedded communication paths, inspecting structured exchanges, and supporting repeatable validation. The interfaces were built in C#/.NET and used alongside embedded hardware.

    Engineering scope

    • UART, SPI, and CAN validation
    • Structured command-response communication
    • Test reporting and diagnostic interfaces
    • Support for verification and data-integrity analysis
