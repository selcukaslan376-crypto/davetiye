Introduction

Software close to the hardware, explained with precision.

My work spans low-level firmware, measurement and test systems, embedded Linux interfaces, and the communication paths that join them.

I focus primarily on modern C—especially C99 and C11—where small distinctions in types, object lifetime, pointer semantics, and memory management have practical consequences. This site is both a professional record and a growing knowledge base for those details.
